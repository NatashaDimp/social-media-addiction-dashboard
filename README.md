# 📊 Social Media Addiction Dashboard

An interactive Excel dashboard analyzing social media usage, addiction risk, sleep patterns, demographics, and user behavior.

## 📌 Project Overview

This project analyzes a dataset of 10,000 social media users to understand patterns in social media usage and their relationship with addiction risk and sleep behavior.

The project focuses on transforming raw user data into meaningful business insights through data cleaning, calculated fields, KPI development, PivotTables, and interactive dashboard visualizations.

## 🎯 Business Questions

* What is the average daily social media usage?
* What proportion of users fall into high or severe addiction levels?
* How does social media usage vary across age groups?
* Which demographics show higher addiction risk?
* How does social media usage relate to sleep duration?
* What percentage of users are classified as having low sleep?
* Which user segments may require greater attention based on usage and addiction risk?

## 🧹 Data Preparation

The dataset was prepared for analysis by:

* Reviewing and validating the raw data
* Creating calculated fields
* Categorizing users into age bands
* Creating addiction-level classifications
* Calculating total daily social media usage
* Creating sleep-risk classifications
* Preparing fields for PivotTable analysis
* Validating KPI calculations

## 📊 Dashboard Features

## 💡 Key Insights

The dashboard is designed to identify patterns between:

**Social Media Usage → Addiction Risk → Sleep Behavior**

The analysis can help identify user segments with higher usage levels, elevated addiction risk, and potentially concerning sleep patterns.
